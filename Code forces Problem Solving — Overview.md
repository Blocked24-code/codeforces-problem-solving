

**Platform:** Codeforces  
**Purpose:** Improve logical reasoning, algorithms, data structures, and independent problem-solving ability.

## Learning Goals

- Understand problem statements and constraints.
    
- Develop my own approach before coding.
    
- Recognize common problem-solving patterns.
    
- Learn to analyze time and space complexity.
    
- Identify mistakes and learn from them.
    

## My Problem-Solving Workflow

1. Read the problem carefully.
    
2. Identify the input, output, and constraints.
    
3. Think of my own approach.
    
4. Ask for hints when stuck.
    
5. Try to discover the solution independently.
    
6. Test my code and reasoning.
    
7. Record what I learned.
    

**Mentoring preference:** I learn best through hints and guided reasoning rather than being given full solution code.
